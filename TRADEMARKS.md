# Arkiv name and logo policy

Arkiv's code and artwork are free software under the
[GNU GPL-3.0-or-later](LICENSE). This page is about something the licence does
not cover: the **name "Arkiv"** and the **Tension Seal** mark (the app icon,
[branding](branding/README.md)) as signs of where a build comes from. It does
not restrict anything the GPL allows you to do with the code or artwork.
GPL-3.0 section 7(e) lets a project decline to grant trademark rights; this is
that statement, and nothing more.

The aim is simple: someone who downloads "Arkiv" with the Tension Seal icon
should be getting this project's build, signed with this project's update key.

## Always fine, no permission needed

* Downloading, using, building, modifying and redistributing **unmodified**
  Arkiv builds under the name Arkiv, including on download sites, mirrors,
  package managers, community lists (FMHY, Reddit, Discord) and commercially.
* Building Arkiv yourself from unmodified source and calling it Arkiv.
* Using the name and icon to refer to Arkiv: reviews, articles, tutorials,
  comparisons, screenshots, videos, links, "works with Arkiv".
* Small changes needed only to package or build Arkiv for a platform or
  distribution (paths, build flags, packaging metadata), as long as the
  description says it is a repackaged build.
* Contributing back: patches and theme proposals to this repository.

## For modified versions (forks)

You may fork Arkiv freely under the GPL. If your distributed version changes
what the app does, please:

* give it a **different name** that is not confusingly similar to "Arkiv"
  (for example, not "Arkiv Pro" or "Arkiv Plus"), and a **different app
  icon**; you can say "based on Arkiv";
* use your own bundle identifier and your own Sparkle feed and signing key,
  so your users never receive updates meant for Arkiv or the reverse;
* not suggest that this project endorses or supports your version.

You keep every GPL right to the code and the artwork itself. If you want to
reuse document-icon artwork or theme packs in a fork, that is allowed by the
GPL; just do not present the result as official Arkiv.

## Not allowed

* Distributing modified builds, or software bundled with adware, malware or
  installers, under the Arkiv name or Tension Seal icon.
* Using the name or icon in a way that implies an official build, official
  support or endorsement when there is none.

## Questions

Open an issue to ask; reasonable uses will usually be welcomed. This policy
may be clarified over time, but never in a way that takes away rights the GPL
gives you.
