Arkiv links to the operating system's libarchive; no separately downloaded libarchive or UnRAR binary is included in the application. The macOS system component's applicable notices are supplied by Apple. For project development and fixture attribution, the upstream libarchive license is reproduced in `licenses/libarchive-COPYING.txt`.

The icon renderer is original project artwork.
