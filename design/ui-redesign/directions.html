Selection

A · Ledger scores best on the stated criteria. Usability: every operation stays one click or one shortcut away; navigation sits where macOS puts it (leading, beside the title). Platform conventions: NSToolbar unified style, NSSearchToolbarItem, NSPathControl, sidebar Settings like System Settings. Visual quality: the brand appears in the welcome canvas, selection and primary actions, not as decoration on every surface. Cost and performance: no tree sidebar to compute or keep in sync; the table stays a view-based NSTableView with reused cells.

B is rejected because the sidebar would have no purpose beyond the path bar. C is a good fallback but would leave Arkiv looking like a generic utility.
